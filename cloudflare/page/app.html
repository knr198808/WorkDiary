◆ 업무 다이어리

연결 정보가 없어요

PC의 업무 다이어리 → 📱 폰 연결 · 웹앱에 있는 QR코드를 폰 카메라로 찍어서 열어주세요.

🔑 PC와 데이터 연결이 필요해요

일정·회원·메모를 보려면 PC의 업무 다이어리 → 📱 폰 연결 · 웹앱 → 웹앱 탭의 QR코드를 폰 카메라로 다시 찍어주세요.

예약 알림은 지금 그대로 받을 수 있어요 (아래 🔔 알림 탭).

✎ 하루 메모 자동 저장

아이폰은 한 번만 이렇게 해주세요

  1. 화면 아래 공유 버튼(네모에 위 화살표)을 누르세요
  2. '홈 화면에 추가'를 누르세요
  3. 홈 화면에 생긴 업무 다이어리 아이콘으로 다시 열면 [알림 켜기] 버튼이 나와요

아이폰은 iOS 16.4 이상, 홈 화면에 추가한 앱에서만 알림을 받을 수 있어요.

크롬에서 열어주세요

지금 브라우저()에서는 알림이 꺼지거나 안 올 수 있어요. 안드로이드는 크롬에서 켜야 가장 안정적이에요.

알림이 꺼져 있어요

아래 버튼을 누르고 허용을 선택하세요.

🔋 알림이 꺼지지 않게 (안드로이드, 한 번만)

  1. 설정 → 애플리케이션 → Chrome (홈 화면에 추가했다면 업무다이어리도)
  2. 배터리 → '제한 없음' 선택
  3. 알림 → 허용 확인
  4. 크롬의 인터넷 사용 기록·사이트 데이터 삭제는 하지 마세요 (알림 연결이 지워져요)
  5. 항상 홈 화면의 업무다이어리 아이콘(또는 크롬)으로 여세요

삼성폰: 설정 → 배터리 → 백그라운드 사용 제한 → '절전 예외 앱'에 Chrome 추가하면 더 확실해요.
